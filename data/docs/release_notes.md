# Lumora Home App — Release Notes

*Fictional sample document used for the Document Q&A with RAG demo.*

## Version 3.4.0 (September 2026)

- **Energy Reports:** a new monthly energy report estimates heating and cooling costs based on run time and the local energy price entered in settings.
- **Multi-home support:** users can now manage up to 5 homes from a single account.
- Added Dutch and Polish translations.
- Fixed an issue where geofencing did not trigger on some Android 15 devices.
- Minimum supported versions are now iOS 17 and Android 12.

## Version 3.3.0 (June 2026)

- **Guest Access:** homeowners can invite guests with time-limited access that expires automatically after a chosen date. Guests can change the temperature but cannot edit schedules or settings.
- **Matter support:** the AeroLink X2 can now be added to Matter-compatible smart home platforms. This requires thermostat firmware 2.8 or later.
- Improved app start-up time by about 40%.
- Fixed a bug where the Adaptive Schedule proposal was shown twice.

## Version 3.2.1 (April 2026)

- Hotfix: resolved a crash on launch for users with more than 20 devices.
- Fixed incorrect Fahrenheit rounding in the temperature graph.

## Version 3.2.0 (March 2026)

- **Dark mode** is now available and follows the system setting by default.
- **Vacation Mode:** set a date range during which the thermostat holds an energy-saving temperature, then automatically returns to the normal schedule.
- Widgets for the iOS and Android home screens.
- Removed support for the legacy AeroLink X1 Wi-Fi bridge; X1 users must use the Lumora Home Classic app.

## Version 3.1.0 (January 2026)

- Two-factor authentication for Lumora Home accounts using an authenticator app.
- Added the ability to export temperature history as a CSV file.
- The app now uses Lumora Cloud API v2; API v1 is deprecated.

## Version 3.0.0 (November 2025)

- Complete redesign of the app interface.
- New onboarding flow with Bluetooth-based setup that replaced the old hotspot method.
- Introduced the Filter Reminders feature for the AeroLink X2.
